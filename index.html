Open-source tools

  • socks5-proxy-checker: find the exact step where a SOCKS5 proxy fails (TCP, greeting, login, CONNECT, HTTPS).
  • proxy-list-health-check: test a whole list of HTTP and SOCKS5 proxies in parallel: status, time, exit IP and cause of each failure.
  • rotating-proxy-test-script: check whether a rotating proxy gives a new exit IP per connection.
  • sticky-session-proxy-tester: measure how long a sticky session really keeps the same exit IP.
  • proxy-speed-test: measure the latency a proxy adds against a direct baseline.
  • proxy-password-special-characters: percent-encode proxy logins with @ : # ! and get working curl, env, requests and Playwright settings.
  • proxy-ip-check: see a proxy's exit IP, country, network owner and timezone in one command.
  • proxy-env-check: see which proxy curl and Python will use for a URL from your environment variables.
  • proxy-list-format-converter: convert proxy lists between host:port:user:pass, user:pass@host:port and URLs.
  • proxy-dnsbl-check: check a proxy exit IP against Spamhaus ZEN and SpamCop.
  • socks5-udp-check: find out whether a SOCKS5 proxy supports UDP.
  • ipv6-leak-check: compare your own IPv4 and IPv6 with the proxy exit to spot IPv6 leaks.
  • proxy-block-log-analyzer: tell whether 403/429 blocks follow specific exit IPs or your request pattern.
  • ip-native-check: is an IP native or broadcast? Compare registration, geolocation and ASN countries, no API key.
  • chatgpt-route-check: one unauthenticated request shows whether OpenAI accepts a network location (401) or not (403).
  • python-http-client-lab: httpx timeouts, aiohttp connection limits, 429 Retry-After and proxy passwords, reproduced with numbers.
  • proxy-error-diagnose: is it a 407, a timeout or a refused connection? Walks one request through an HTTP or SOCKS5 proxy and stops at the failing step.
  • pac-file-tester: test a PAC file locally and see which proxy FindProxyForURL returns for each URL.
  • proxy-connect-port-check: which destination ports a proxy will tunnel to, tested through HTTP CONNECT or SOCKS5.
  • proxy302-mcp: MCP server: your proxies, usage and IP checks as tools for Claude, Cursor and other AI agents (local or hosted).
  • proxy302-cli: command-line client for rotating residential, static ISP and datacenter proxies.
  • proxy302-claude-plugins (Claude Code) and proxy302-dify-plugin (Dify, read-only).
